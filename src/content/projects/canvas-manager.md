Keeps a Canvas evidence layer (`raw/`) and a learning-notes layer (`wiki/`)
in sync on a schedule you control. Has a Lite mode for schools that disable
self-service API tokens, and an optional companion,
[CourseManager](https://github.com/Geek96/course-manager), that synthesizes
assignment overviews and deadline views on top of it.
